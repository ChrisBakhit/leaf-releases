# Leaf downloads

Official Windows downloads and update files for Leaf.

[Download the latest Windows installer](https://github.com/ChrisBakhit/leaf-releases/releases/latest) · [Release history](https://github.com/ChrisBakhit/leaf-releases/releases)

## Updates

Leaf 0.1.13 and later use this public release channel. No GitHub account is needed to download the installer or check for updates. Use Leaf's update controls to check, download, and restart when ready.

If an older installation asks for GitHub access, install the latest installer here once to move onto the public channel.

## Repository scope

This repository contains release files and download documentation. Leaf development source and Git history are maintained separately in a private repository. The distributed application is not offered as open-source software; third-party components retain their own licenses and notices.

Current Windows installers are unsigned pilot builds. macOS and mobile downloads are not published here yet.
